# AI Usage Logs

Transparent AI disclosure logs for course lab reports, organized by team role:

- `r1-backend/` — Backend / Domain (.NET 10)
- `r2-frontend/` — Frontend / QA / Load Testing
- `r3-devops/` — DevOps / Cloud Infrastructure
- `r4-obs-pm/` — Integration / Observability / Documentation

Each log file should summarize: tools used, tasks delegated, verification steps performed, and key prompts/decisions without secrets or private local paths.
